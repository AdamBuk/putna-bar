# Fotografie Putna Bar

V této složce se nachází lokální fotografie pro web Putna Bar.

## Jak vložit vaše reálné fotografie (z Instagramu / Google Maps):
Stačí jednoduše nakopírovat vaše fotky do této složky (`public/images/`) se stejnými názvy:

| Název souboru | Kde se na webu zobrazuje |
|---|---|
| `hero.jpg` | Hlavní fotka úvodní sekce (atmosféra baru, teplé osvětlení) |
| `interior.jpg` | Interiér baru (ratanová křesílka, barevné stěny, lampičky) |
| `garden.jpg` | Letní venkovní zahrádka v uličce Tomkova |
| `dog-friendly.jpg` | Dog friendly zákoutí |
| `signature-velvet.jpg` | Fotka drinku Putna Velvet |
| `signature-salon.jpg` | Fotka drinku Salon Králové |
| `signature-sunset.jpg` | Fotka drinku Sunset |
| `cocktail-old-fashioned.jpg` | Fotka Old Fashioned |
| `cocktail-martini.jpg` | Fotka Espresso Martini |
| `cocktail-basil.jpg` | Fotka Gin Basil Smash |
| `beer-draft.jpg` | Čepované pivo |
| `cafe-espresso.jpg` | Výběrová káva / Espresso Tonic |
| `gallery-1.jpg` až `gallery-4.jpg` | Fotky v sekci Atmosféra |

Po nakopírování se fotky na webu ihned automaticky zobrazí bez nutnosti měnit kód!
Pokud chcete změnit formát (např. na `.png` nebo `.webp`), stačí upravit cesty v `src/config/images.ts`.
